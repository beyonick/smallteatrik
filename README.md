# Маленький театрик кукол — сайт

Театр кукол Владимира Злобина, Геленджик.
Статический сайт без сборки: открывается как есть, деплоится куда угодно.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: герой → афиша → ближайшие показы → о театре → как проходит спектакль → актёры → контакты |
| `afisha.html` | Афиша: все спектакли репертуара с фильтром по возрасту и наличию даты |
| `raspisanie.html` | Расписание: ближайшие показы по месяцам, площадки, вопросы про билеты |
| `o-teatre.html` | О театре: как устроены, как проходит спектакль, площадки, актёры, вопросы, контакты |
| `aktery.html` | Наши актёры: четыре актрисы, как устроена работа за ширмой, кадры со спектаклей |
| `spektakl.html?id=<id>` | Типовая страница спектакля. Без `id` открывает ближайший показ |
| `admin.html` | Админка: худрук заводит и правит спектакли |

## Как запустить

Из папки `Сайт`:

```bash
python -m http.server 8123
```

Затем открыть http://localhost:8123. Просто двойным кликом по `index.html` тоже работает,
но часть браузеров ограничивает `localStorage` на `file://` — админку лучше смотреть через сервер.

## Данные спектаклей

Всё лежит в `assets/js/store.js`:

* `DEFAULTS` — четырнадцать спектаклей репертуара, собранных из афиш во ВКонтакте;
* `load()` / `save()` — сейчас это `localStorage` браузера (`smallteatrik:shows:v2`).

**Это прототип хранения.** Данные живут в браузере того, кто их завёл: на другом
компьютере их не видно, при очистке данных сайта они пропадут. В админке есть
«Выгрузить JSON» / «Загрузить JSON» — так их можно перенести или отдать разработчику.

Когда появится бэкенд, меняются только `load()` и `save()` в `store.js` —
остальной код страниц трогать не нужно.

Поля спектакля:

| Поле | Что значит |
|---|---|
| `id` | адрес страницы: `spektakl.html?id=kolobok` |
| `title`, `tagline` | название и подзаголовок на карточке |
| `age`, `duration`, `price` | возраст, минуты, рубли |
| `date` | ближайший показ, `ГГГГ-ММ-ДДTчч:мм`; пусто — карточка без даты |
| `venue` | площадка |
| `tone`, `art` | цвет спектакля: шапка страницы и заливка карточки |
| `mascot` | вырезка куклы, `assets/mascot/<id>.webp`; пусто — рисуется плейсхолдер |
| `photos` | кадры для галереи на странице спектакля |
| `short`, `description` | короткий текст для карточки и абзацы для страницы |
| `ticketUrl` | ссылка на кассу |
| `published` | показывать ли на сайте |

## Жёлтая лента с петлёй

Лента — SVG-путь с жёлтой обводкой и надписью по нему. Лент три вида:

* **верхняя** (под геро-блоком) — без завитка, правым краем уходит наверх, на геро-блок;
* **`.ribbon-titles`** — после «Ближайших показов» на главной, с названиями спектаклей;
  левым краем ложится на блок снизу. Раньше на этом месте была тёмная бегущая строка;
* **`.ribbon-mid`** — с завитком, на главной и на странице «О театре».

В разметке лежит только осевая линия (`<path>` в `<defs>`) и надпись по ней.
Тело рисует `assets/js/ribbon.js`: он идёт по оси, считает нормали и строит
залитый контур **постоянной ширины** (`HALF` в начале файла). Живость даётся
изгибами самой оси, а не толщиной. Снизу лежит тёмная копия со сдвигом —
это толщина ленты.

Самопересечение скрипт находит сам, перебирая точки оси. Нижняя нить убирается
маской (вырез идёт вдоль верхней нити), а верхняя рисуется заново поверх —
с размытой тенью и чуть более тёмной заливкой, как изнанка ленты. Форму пути
можно менять свободно: пересечение пересчитается само.

Вся лента ещё и медленно покачивается — `@keyframes ribbonfloat`, у каждой своя
длительность и сдвиг фазы, чтобы они не ходили синхронно.

Если скрипт не отработал, в разметке остаётся `.ribbon-fallback` — та же линия
обычной обводкой, без объёма.

Фраза берётся из `data-phrase` на `<div class="ribbon">`, повторяется по всей длине
пути и едет по кругу: `assets/js/ribbon.js` двигает `startOffset` и обнуляет сдвиг
на длине одного повтора, поэтому шва не видно. Анимация останавливается, когда лента
ушла с экрана, вкладка неактивна или в системе включено «уменьшить движение».

Лента лежит поверх соседних блоков: у `.ribbon` отрицательные `margin-top` и
`margin-bottom` и свой `z-index`, а у геро-блоков увеличен нижний отступ, чтобы петля
ложилась на пустое место, а не на текст. Модификатор `.ribbon-mid` — для лент в середине
страницы: они заходят в основном на блок сверху.

Толщину линии задаёт `.ribbon .band` в `assets/css/site.css`, текст стоит ровно
по центру линии за счёт `dominant-baseline:central`.

## Меню на телефоне

Узкие экраны прячут обычное меню, поэтому в шапке появляется бургер, а «Купить
билет» прижимается к правому краю. Панель (`.nav-menu`) открывается на весь экран
под шапкой: шапка остаётся сверху, бургер превращается в крестик. Ссылки — цветными
плашками, в углу попугай из «Айболита». Закрывается по Esc, по клику на ссылку и
когда экран становится шире 620 px. Разметка лежит в каждой странице, поведение —
в `assets/js/menu.js`.

## Шрифты

* Заголовки — **ST Izhora** (`assets/fonts/ST-Izhora-free.woff2` + `.otf` запасным),
  подключён через `@font-face`, токен `--disp`. Начертание одно, поэтому в `html`
  стоит `font-synthesis-weight:none` — браузер не рисует искусственный жир, и
  прописанные в стилях `font-weight:800/900` не портят рисунок букв.
* Текст — **Onest** с Google Fonts, токен `--sans`.

## Куклы на карточках

Вырезки лежат в `assets/mascot/` и подставляются из поля `mascot` в `store.js`.
Плашка карточки больше не обрезает содержимое: кукла позиционируется абсолютно
(высота плашки задана через `aspect-ratio`, а от него проценты не считаются),
слегка выступает над плашкой, а при наведении увеличивается и поворачивается —
и вылезает за карточку. Соседние карточки не перекрывают её: у наведённой
поднимается `z-index`. Тот же приём на главной и на странице спектакля — `.mascot img`.

На телефоне ховера нет, поэтому там куклу поднимает прокрутка:
`assets/js/lift.js` считает, насколько карточка близка к середине экрана,
и кладёт это число (0…1) в переменную `--lift`, а из неё CSS собирает масштаб,
наклон и тень. Считается только для карточек в кадре и только в
`requestAnimationFrame`. Включается по `(hover:none)` и выключается при
«уменьшить движение».

## Дизайн

Закруглённые карточки с небольшим наклоном, крупный дисплейный шрифт
(Unbounded + Onest), яркая палитра, 3D-маскоты вместо иллюстраций.
Токены — в начале `assets/css/site.css`.
